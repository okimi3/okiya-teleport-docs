# 利用制限

<p className="lead-text">テレポートを利用できるプレイヤーを、接続ごとに設定できます。<br />最初は「全員」で試して、必要に応じて制限を付けてね。</p>

## 1. 利用モードを選ぶ

Prefab本体のInspectorで **テレポート管理 → テレポート接続管理** を開きます。<br />設定したい接続を開き、**オプション設定 → 利用モード** を選びます。

![全員、ホワイトリスト、ブラックリストから利用モードを選ぶInspector](/img/screenshots/access-restriction/mode-dropdown.png)

Ver.2では、次の3つから **1つ** を選びます。

| 利用モード | 利用できるプレイヤー |
| --- | --- |
| 全員 | 全員が利用可能 |
| ホワイトリスト | 登録したVRChat表示名と完全一致したプレイヤーだけ |
| ブラックリスト | 登録したVRChat表示名と完全一致したプレイヤー以外 |

## 2. ホワイトリストを設定する

登録したプレイヤーだけに利用を許可したい場合は、**ホワイトリスト** を選びます。<br />名前の欄へ、そのプレイヤーの **VRChat表示名** を入力してね。

![VRChat表示名を登録したホワイトリストの例](/img/screenshots/access-restriction/whitelist.png)

画像の名前は説明例です。<br />利用を許可したいプレイヤーの実際の表示名を登録してください。

**＋ 追加** で入力欄を増やせます。<br />**－ 最後を削除** は、最後の入力欄を削除します。

## 3. ブラックリストを設定する

登録したプレイヤーの利用を禁止したい場合は、**ブラックリスト** を選びます。<br />名前の欄へ、利用を禁止するプレイヤーの **VRChat表示名** を入力します。

![VRChat表示名を登録したブラックリストの例](/img/screenshots/access-restriction/blacklist.png)

画像の名前は説明例です。<br />登録した表示名と完全一致するプレイヤーは、この接続を利用できません。<br />入力欄の追加・削除は、ホワイトリストと同じ操作です。

## 4. 表示名は完全一致で判定する

:::important VRChat表示名を正確に入力してね
**大文字・小文字、スペース、記号、絵文字も区別** します。<br />実際のVRChat表示名と同じ文字を入力してください。
:::

例えば、次の名前はすべて別の名前として扱われます。

| 名前の例 | 違い |
| --- | --- |
| `OKIYA` | スペースや記号のない名前 |
| `OKI YA` | 途中にスペースがある名前 |
| `★OKIYA` | 先頭に記号がある名前 |

同じ名前を重複登録すると、Inspectorに警告が表示されます。<br />警告が出た場合は、リストの入力内容を確認してね。

## 5. 利用できなかった場合の動作

**拒否時の反応** で、利用を拒否したときの動作を選びます。

| 設定 | 拒否したときの動作 |
| --- | --- |
| 何もしない | テレポートせず、拒否メッセージも表示しない |
| メッセージ | テレポートせず、設定した拒否メッセージを表示する |

![拒否時の反応を何もしないに設定したInspectorの例](/img/screenshots/access-restriction/denied-none.png)

### メッセージを表示する

**拒否時の反応 → メッセージ** を選ぶと、文章と時間を設定できます。

![拒否メッセージ、表示時間、フェードアウト時間を設定するInspectorの例](/img/screenshots/access-restriction/denied-message.png)

| 項目 | 設定する内容 |
| --- | --- |
| 拒否メッセージ | 利用できなかった本人へ表示する文章 |
| 表示時間 | メッセージを表示する時間 |
| フェードアウト時間 | メッセージが消えるまでのフェード時間 |

画像の文章と時間は説明例です。<br />メッセージは、**拒否された本人にだけ** 表示されます。
