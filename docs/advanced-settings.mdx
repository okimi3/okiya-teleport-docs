# 詳細設定

<p className="lead-text">
このページでは、Prefab本体Inspectorの <strong>基本的に触らない設定</strong> を説明します。<br />
主に開発時の確認・表示テスト・トラブル対応で使用する項目です。<br />
<strong>通常利用では、基本的に変更しなくてOKです。</strong>
</p>

:::warning 基本的には変更しなくてOK
この設定は、開発時の確認やトラブル対応で使用するものです。<br />
通常のテレポート設定では変更する必要はありません。
:::

Prefab本体を選択し、Inspectorの **基本的に触らない設定** を開くと、次の3項目を確認できます。

![基本的に触らない設定を開き、Desktop / VR判定ログ、VR表示を強制テスト、到着通知の内部参照を自動修復が見えるInspector](/img/screenshots/advanced-settings/advanced-settings-overview.png)

| 項目 | 主な用途 | 通常時 |
| --- | --- | --- |
| Desktop / VR判定ログ | Desktop / VR判定の確認 | OFF |
| VR表示を強制テスト | VR向け表示の確認 | OFF |
| 到着通知の内部参照を自動修復 | 到着通知の内部参照を修復 | 通常は使用しない |

## 1. Desktop / VR判定ログ

**Desktop / VR判定ログ** は、DesktopとVRの判定状況を確認したいときに使うテスト用設定です。<br />
開発時の確認やトラブルの切り分けに使用し、通常利用では **OFF** のままで問題ありません。

:::tip いつ使う？
DesktopとVRの判定が想定どおりになっているか確認したい場合など、動作確認時だけ使用してね。
:::

## 2. VR表示を強制テスト

**VR表示を強制テスト** は、VR向け表示の確認に使用するテスト用設定です。<br />
通常利用では **OFF** のまま使用してね。

:::important VR対応をONにする設定ではありません
VRで使用するために、この項目をONにする必要はありません。<br />
表示確認・テスト時に使用する項目です。
:::

## 3. 到着通知の内部参照を自動修復

**到着通知の内部参照を自動修復** は、到着通知で使用する内部参照を修復するための、トラブル対応用ボタンです。<br />
通常利用では押す必要はありません。

到着通知が動かない場合は、まず[トラブルシューティング](./troubleshooting)で通常設定とConsoleを確認してください。<br />
通常の設定に問題がなく、内部参照が正しくつながっていないと思われる場合など、修復が必要なときに使用してね。
