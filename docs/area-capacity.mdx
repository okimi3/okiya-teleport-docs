# エリア・定員

<p className="lead-text">到着エリアの人数を数え、入場できる人数に上限を設けます。</p>

## エリアを用意する

人数を判定したい範囲へエリア用のTriggerを配置します。床だけでなく、プレイヤーが範囲内にいる間しっかり重なる高さと広さにします。

<div className="screenshot-placeholder"><div><strong>エリア範囲の配置</strong><small>差し替え先: Trigger範囲が見えるSceneビュー</small></div></div>

## 定員を設定する

エリア側または入口側の定員項目へ、許可する最大人数を入力します。0の扱いは設定方式によって異なるため、無制限なのか入場不可なのかをテストしてください。

## 動作の流れ

1. 入口で移動要求が発生する
2. 対象エリアの現在人数を確認する
3. 空きがあれば移動を実行する
4. 満員なら移動を止め、必要に応じてメッセージを出す

:::warning 判定範囲に注意
エリアのTriggerに隙間があると、見た目では室内にいても人数へ含まれない場合があります。出入口や段差も含めて範囲を確認してください。
:::

## 複数人で確認する

定員機能は、可能であれば複数クライアントを使って確認します。

<ul className="check-list">
  <li>入場すると人数が増える</li>
  <li>退場すると人数が減る</li>
  <li>定員ちょうどまでは入場できる</li>
  <li>上限を超える移動は実行されない</li>
</ul>

満員時の案内は、[満員時メッセージ](./full-message)で設定します。
