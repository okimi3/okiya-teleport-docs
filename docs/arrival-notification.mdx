# 到着通知

<p className="lead-text">テレポート完了後に場所名や案内を表示し、到着したことを伝えます。</p>

## 通知を設定する

到着先に対応する通知UIを用意し、到着時に表示する内容を設定します。場所名だけで十分な場合は短く、次の操作が必要な場合は補足を1行追加します。

```text
ロビーに到着しました
```

## 読みやすくする

- 場所名は1行で表示する
- 背景とのコントラストを確保する
- Fadeと重なる場合は、画面が見え始めてから表示する
- 操作が必要な案内は、自動で消えるまでの時間を長めにする

## 複数の入口から到着する場合

通知内容を入口に持たせるか、到着先に持たせるかを統一します。同じ場所へ複数経路から来ても同じ案内を出したい場合は、到着先側で管理すると変更が楽です。

:::tip 演出は必要な場所だけ
短い距離の移動や頻繁に使う入口では、通知が煩わしくなることがあります。場所の切り替わりを伝える必要がある場面に絞ると効果的です。
:::
