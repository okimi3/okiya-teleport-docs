# テレポート接続

<p className="lead-text">ポイント同士の接続は、Prefab本体のInspectorにある「テレポート接続管理」から設定します。<br />画面に写っているポイント名は説明用の例です。<br />自分のワールドに合う名前を使ってね。</p>

## 1. 接続を追加する

先に[テレポートポイント](./teleport-point)で2つのポイントを用意します。<br />最初は、どちらも **両方（入口＋出口）** にしておくと行き来に使いやすいです。<br />Scene上のPrefab本体を選び、**テレポート管理 → テレポート接続管理** を開いて **＋ 接続を追加** を押してね。

![テレポート接続管理の接続追加ボタン](/img/screenshots/connection/add-connection.png)

接続を開くと、接続元やテレポート先などをまとめて設定できます。

![通常・双方向・接触で接続したInspectorの例](/img/screenshots/quick-start/connection-details.png)

最初は次の設定がおすすめです。

| 項目 | 最初のおすすめ |
| --- | --- |
| テレポート方式 | 通常 |
| 接続方向 | **双方向** |
| 発動方法 | 接触 |
| 利用モード | 全員 |

画像の「玄関」「リビング」は名前の一例です。

## 2. 接続元を選ぶ

**接続元** で、テレポートを始めるポイントを選びます。<br />選べるのは **テレポート入口** または **両方（入口＋出口）** のポイントです。<br />同じ接続元を複数の接続に重複登録することはできません。

![接続元のポイントを選ぶドロップダウン](/img/screenshots/connection/source-dropdown.png)

画像の「玄関だよ」は選択例です。

## 3. テレポート方式とテレポート先を決める

**テレポート方式** は **通常 / ランダム / 分散** から選びます。<br />最初は **通常** にすると、テレポート先を1つ選ぶだけで試せます。

![テレポート方式の通常、ランダム、分散](/img/screenshots/connection/mode-dropdown.png)

**テレポート先設定 → テレポート先** で、到着させたいポイントを選びます。<br />画像の「リビングだぞ」はテレポート先の一例です。

![テレポート先のポイントを選ぶドロップダウン](/img/screenshots/connection/destination-dropdown.png)

複数のテレポート先を使いたい場合は、[ランダム](./random)や[分散](./distribution)を確認してね。

## 4. 接続方向を選ぶ

**一方通行** は接続元からテレポート先へ進む設定、**双方向** は両方のポイントから行き来する設定です。

![接続方向の一方通行と双方向](/img/screenshots/connection/direction-dropdown.png)

迷ったら、最初は **双方向** にして行き・帰りを確認してね。<br />片道だけにしたい場合は **一方通行** を選びます。

### 一方通行：A → B

接続元からテレポート先へテレポートできます。<br />この接続だけでは、反対側から戻れません。

![一方通行では片方向の矢印が表示される例](/img/screenshots/quick-start/one-way-arrow.png)

### 双方向：A ↔ B

どちらのポイントからでも、もう片方へテレポートできます。<br />両方のポイントを **両方（入口＋出口）** にして使ってね。

![双方向では両方向の矢印が表示される例](/img/screenshots/quick-start/two-way-arrow.png)

## 5. 発動方法を選ぶ

**接触** は入口に入ると発動します。<br />**トリガー** は入口で操作して発動する方法です。

![発動方法の接触とトリガー](/img/screenshots/connection/activation-dropdown.png)

トリガーを選んだときだけ **トリガー表示設定** が出ます。

![双方向・トリガーで設定した接続Inspectorの例](/img/screenshots/connection/trigger-details.png)

画像のポイント名と操作テキストは説明例です。

**操作テキスト** を設定し、**ミニプレビュー** で表示を確認できます。<br />操作テキストを空欄にすると文字は表示されません。

![トリガーの操作テキストを入力する欄](/img/screenshots/connection/trigger-text.png)

入力した文字の見え方は、**ミニプレビュー** で確認してね。

![操作テキストのミニプレビュー](/img/screenshots/connection/trigger-preview.png)

## 6. 利用モードとFadeを確認する

**オプション設定** の **利用モード** は **全員 / ホワイトリスト / ブラックリスト** から選びます。<br />最初は **全員** で動作を確認してね。

![利用モードの全員、ホワイトリスト、ブラックリスト](/img/screenshots/connection/access-dropdown.png)

![利用モードと拒否時の反応があるオプション設定の例](/img/screenshots/connection/options.png)

同じオプション設定に **Fadeを使用** と **Fade Out / 完全暗転の維持 / Fade In** があります。<br />暗転の見た目は共通Fadeデザインから設定します。<br />詳しくは[Fade](./fade)へ。

![Fade使用とFade Out、完全暗転の維持、Fade Inの設定例](/img/screenshots/connection/fade-settings.png)

画像の時間は説明例なので、演出に合わせて調整してね。

## 7. 接続一覧を確認する

一覧には **接続番号｜接続元 → テレポート先｜方式・発動方法** のように表示されます。<br />双方向の接続では矢印が **↔** になります。<br />番号と名前を見て、意図した組み合わせか確認してね。

![接続番号、接続元、テレポート先、方式、発動方法が分かる接続一覧](/img/screenshots/connection/connection-list.png)

右端の **≡** から接続を並び替えられます。<br />

![接続右端の並び替えハンドル](/img/screenshots/connection/reorder-handle.png)

接続を消す場合は、その接続を開いて **この接続を削除** を押します。

![接続下部の削除ボタンが見えるInspectorの例](/img/screenshots/connection/connection-details.png)

この画像は一方通行にした場合の例です。<br />接続を削除しても、テレポートポイントは別に管理します。

## 8. Playで試す

はじめは **通常・双方向・接触・利用モード：全員** にして、片方のポイントへ入ってみてね。<br />もう片方へテレポートできたら、反対側から戻れることも確認します。<br />ここまでできれば基本の接続はOKだよ。
