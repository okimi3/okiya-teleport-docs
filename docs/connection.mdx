# テレポート接続

<p className="lead-text">入口と行き先の関係は、Prefab本体のInspectorにある「テレポート接続管理」から設定します。画面に写っているポイント名は説明用の例です。自分のワールドに合う名前を使ってね。</p>

## 1. 接続を追加する

先に[テレポートポイント](./teleport-point)で入口と出口を用意します。Scene上のPrefab本体を選び、**テレポート管理 → テレポート接続管理** を開いて **＋ 接続を追加** を押してね。

![テレポート接続管理の接続追加ボタン](/img/screenshots/connection/add-connection.png)

接続を開くと、接続元や行き先などをまとめて設定できます。

![接続1件を開いたInspectorの全体像](/img/screenshots/connection/connection-details.png)

## 2. 接続元を選ぶ

**接続元** で、テレポートを始めるポイントを選びます。選べるのは **テレポート入口** または **両方（入口＋出口）** のポイントです。同じ接続元を複数の接続に重複登録することはできません。

![接続元のポイントを選ぶドロップダウン](/img/screenshots/connection/source-dropdown.png)

画像の「玄関だよ」は選択例です。

## 3. テレポート方式と行き先を決める

**テレポート方式** は **通常 / ランダム / 分散** から選びます。最初は **通常** にすると、行き先を1つ選ぶだけで試せます。

![テレポート方式の通常、ランダム、分散](/img/screenshots/connection/mode-dropdown.png)

**テレポート先設定 → テレポート先** で、到着させたいポイントを選びます。画像の「リビングだぞ」は行き先の一例です。

![テレポート先のポイントを選ぶドロップダウン](/img/screenshots/connection/destination-dropdown.png)

複数の行き先を使いたい場合は、[ランダム](./random)や[分散](./distribution)を確認してね。

## 4. 接続方向を選ぶ

**一方通行** は接続元からテレポート先へ進む設定、**双方向** は両方のポイントから行き来する設定です。

![接続方向の一方通行と双方向](/img/screenshots/connection/direction-dropdown.png)

まず片道で動かすなら **一方通行** を選べばOKです。

## 5. 発動方法を選ぶ

**接触** は入口に入ると発動します。**トリガー** は入口で操作して発動する方法です。

![発動方法の接触とトリガー](/img/screenshots/connection/activation-dropdown.png)

トリガーを選んだときだけ **トリガー表示設定** が出ます。**操作テキスト** を設定し、**ミニプレビュー** で表示を確認できます。操作テキストを空欄にすると文字は表示されません。

## 6. 利用モードとFadeを確認する

**オプション設定** の **利用モード** は **全員 / ホワイトリスト / ブラックリスト** から選びます。最初は **全員** で動作を確認してね。

![利用モードの全員、ホワイトリスト、ブラックリスト](/img/screenshots/connection/access-dropdown.png)

同じオプション設定に **Fadeを使用** と **Fade Out / 完全暗転の維持 / Fade In** があります。暗転の見た目は共通Fadeデザインから設定します。詳しくは[Fade](./fade)へ。

## 7. 接続一覧を確認する

一覧には **接続番号｜接続元 → テレポート先｜方式・発動方法** のように表示されます。双方向の接続では矢印が **↔** になります。番号と名前を見て、意図した組み合わせか確認してね。

![接続番号、接続元、テレポート先、方式、発動方法が分かる接続一覧](/img/screenshots/connection/connection-list.png)

右端の **≡** から接続を並び替えられます。接続を消す場合は、その接続を開いて **この接続を削除** を押します。

## 8. Playで試す

はじめは **通常・一方通行・接触・利用モード：全員** にして、入口から指定した出口へテレポートできるか確認しましょう。ここまでできれば基本の接続はOKだよ。
