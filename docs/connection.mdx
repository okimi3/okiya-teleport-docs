# テレポート接続

<p className="lead-text">ポイント同士の接続は、Prefab本体のInspectorにある「テレポート接続管理」から設定します。<br />
画面に写っているポイント名は説明用の例です。<br />
自分のワールドに合う名前を使ってね。</p>

## 1. 接続を追加する

先に[テレポートポイント](./teleport-point)で2つのポイントを用意します。<br />
最初は、どちらも **両方（入口＋出口）** にしておくと行き来に使いやすいです。<br />
Scene上のPrefab本体を選び、**テレポート管理 → テレポート接続管理** を開きます。<br />
接続がまだ作られていない場合は、「接続はまだありません」と表示されます。<br />
**＋ 接続を追加** を押して、最初の接続を作ってね。

![接続数0、接続元に使えるポイント数3と接続追加ボタンが見えるInspectorの例](/img/screenshots/connection/add-connection.png)

**接続数** は、現在作成されているテレポート接続の数です。<br />
接続を追加すると、この数も増えていきます。<br />
**接続元に使えるポイント数** では、現在テレポート元として使用できるポイントの数を確認できます。

画像の「0」「3」は説明例です。<br />
「接続はまだありません」は、最初の接続を作る前の案内です。

**✓ 最初の接続を追加して、接続数が1になり、接続の設定欄が表示されればOKです。**

接続を開くと、接続元やテレポート先などをまとめて設定できます。

![通常・双方向・接触で接続したInspectorの例](/img/screenshots/quick-start/connection-details.png)

最初は次の設定で動作を確認し、用途に応じて変更してね。

| 項目 | 最初のおすすめ |
| --- | --- |
| テレポート方式 | 通常 |
| 接続方向 | **双方向** |
| 発動方法 | 接触 |
| 利用モード | 全員 |

画像の「玄関」「リビング」は名前の一例です。

## 2. 接続元を選ぶ

**接続元** で、テレポートを始めるポイントを選びます。<br />
選べるのは **テレポート入口** または **両方（入口＋出口）** のポイントです。<br />
同じ接続元を複数の接続に重複登録することはできません。

![接続元のポイントを選ぶドロップダウン](/img/screenshots/connection/source-dropdown.png)

画像の「玄関だよ」は選択例です。

## 3. テレポート方式とテレポート先を決める

**テレポート方式** は **通常 / ランダム / 分散** から選びます。<br />
最初は **通常** にすると、テレポート先を1つ選ぶだけで試せます。

![テレポート方式の通常、ランダム、分散](/img/screenshots/connection/mode-dropdown.png)

| 方式 | テレポート先の決め方 |
| --- | --- |
| 通常 | 1つのテレポート先を指定する基本方式 |
| ランダム | 複数候補から抽選 |
| 分散 | 人数や空き状況などを使って選択 |

**テレポート先設定 → テレポート先** で、到着させたいポイントを選びます。<br />
画像の「リビングだぞ」はテレポート先の一例です。

![テレポート先のポイントを選ぶドロップダウン](/img/screenshots/connection/destination-dropdown.png)

複数のテレポート先を使いたい場合は、[ランダム](./random)や[分散](./distribution)を確認してね。

## 4. 接続方向を選ぶ

**一方通行** は接続元からテレポート先へ進む設定、**双方向** は両方のポイントから行き来する設定です。

![接続方向の一方通行と双方向](/img/screenshots/connection/direction-dropdown.png)

迷ったら、最初は **双方向** にして行き・帰りを確認してね。<br />
片道だけにしたい場合は **一方通行** を選びます。

### 一方通行：A → B

接続元からテレポート先へテレポートできます。<br />
この接続だけでは、反対側から元のポイントへ戻れません。

**一方通行＋接触** では、テレポート先が **両方（入口＋出口）** でも、別の接続の接続元として使われていなければ、到着側の不要な接触判定は自動で無効になります。<br />
到着先として使うだけで、不要な接触判定が残ることを防ぎます。<br />
別の接続の接続元として使っている場合は、入口機能が必要なため、接触判定は有効なままです。

![一方通行では片方向の矢印が表示される例](/img/screenshots/quick-start/one-way-arrow.png)

### 双方向：A ↔ B

どちらのポイントからでも、もう片方へテレポートできます。<br />
**双方向で使用する場合は、両方のポイントを `両方（入口＋出口）` に設定します。**

![双方向では両方向の矢印が表示される例](/img/screenshots/quick-start/two-way-arrow.png)

**✓ 接続一覧が `A ↔ B` になっていれば、双方向で接続されています。**

## 5. 発動方法を選ぶ

**接触** はポイントの判定に入るとテレポートが発動します。<br />
**トリガー** はポイントで操作するとテレポートが発動します。

![発動方法の接触とトリガー](/img/screenshots/connection/activation-dropdown.png)

トリガーを選んだときだけ **トリガー表示設定** が出ます。

![双方向・トリガーで設定した接続Inspectorの例](/img/screenshots/connection/trigger-details.png)

画像のポイント名と操作テキストは説明例です。

**操作テキスト** を設定し、**ミニプレビュー** で表示を確認できます。<br />
操作テキストを空欄にすると文字は表示されません。

![トリガーの操作テキストを入力する欄](/img/screenshots/connection/trigger-text.png)

入力した文字の見え方は、**ミニプレビュー** で確認してね。

![操作テキストのミニプレビュー](/img/screenshots/connection/trigger-preview.png)

**✓ ミニプレビューに設定した操作テキストが表示されればOKです。**

## 6. 利用モードとFadeを確認する

**オプション設定** の **利用モード** では、この接続を利用できるプレイヤーを設定できます。<br />
**全員 / ホワイトリスト / ブラックリスト** から選択できます。<br />
最初は **全員** で動作確認してね。

![利用モードの全員、ホワイトリスト、ブラックリスト](/img/screenshots/connection/access-dropdown.png)

詳しい設定は[利用制限](./access-restriction)で確認できます。

同じ **オプション設定** で、接続ごとに **Fadeを使用** するかを選びます。<br />
**Fade Out / 完全暗転の維持 / Fade In** の時間も設定できます。

![利用モードとFadeの項目があるオプション設定の例](/img/screenshots/connection/options.png)

画像の時間は説明例なので、演出に合わせて調整してね。<br />
Fadeの見た目など、詳しい設定は[Fade](./fade)で確認できます。

## 7. 接続一覧を確認する

一覧には **接続番号｜接続元 → / ↔ テレポート先｜方式・発動方法** のように表示されます。

- **→**：一方通行
- **↔**：双方向
- **通常・接触** など：テレポート方式と発動方法

![接続番号、接続元、テレポート先、方式、発動方法が分かる接続一覧](/img/screenshots/connection/connection-list.png)

画像内のポイント名は説明例です。

**✓ 接続元・テレポート先・矢印・方式・発動方法が意図した設定になっていればOKです。**

右端の **≡** をドラッグすると、接続を並び替えられます。

![接続右端の並び替えハンドル](/img/screenshots/connection/reorder-handle.png)

接続を削除する場合は、削除したい接続を開いて **この接続を削除** を押します。

![双方向・接触の接続詳細と削除ボタンが見えるInspectorの例](/img/screenshots/connection/connection-details.png)

接続を削除しても、登録済みのテレポートポイント自体は削除されません。<br />
画像内の名前と設定値は説明例です。

## 8. Playで試す

最初は **通常・双方向・接触・利用モード：全員** で確認します。<br />
片方のポイントへ入り、もう片方へテレポートできることを確認してね。<br />
そのあと反対側から入り、元のポイントへ戻れれば双方向の基本接続は完成です。

**✓ 行ける ＋ 戻れる、の両方が確認できればOKです。**
