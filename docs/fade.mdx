# Fade

<p className="lead-text">移動の直前と直後に画面を覆い、位置が切り替わる瞬間を自然に見せます。</p>

## 基本の流れ

1. フェードアウトを開始する
2. 画面が覆われたタイミングで移動する
3. 到着後にフェードインする

## 設定する

入口の演出設定でFadeを有効にし、必要に応じて色と時間を調整します。最初は短めの値から試し、移動が見えてしまう場合だけ少し長くします。

## 調整の目安

| 項目 | 考え方 |
| --- | --- |
| フェード色 | 黒は落ち着いた印象、白は明るい演出に向きます |
| フェードアウト | 移動前の違和感を隠せる長さにします |
| 暗転時間 | 長すぎると操作不能に感じるため、必要最小限にします |
| フェードイン | 到着先を認識できる速さにします |

:::caution 快適性
急な明滅や長い暗転は負担になることがあります。短時間で何度も移動する導線では、特に控えめな演出にしてください。
:::

## 動作確認

低いフレームレートでも移動の瞬間が露出しないか、連続で入口へ入ったときに画面が覆われたままにならないかを確認します。
