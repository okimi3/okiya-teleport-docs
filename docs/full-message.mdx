# 満員時メッセージ

<p className="lead-text">定員に達して移動できないとき、プレイヤーへ短い案内を表示します。</p>

## メッセージを用意する

満員時に表示するUIまたはメッセージオブジェクトを割り当てます。文章は短くし、「なぜ移動できないか」と「次にどうすればよいか」が伝わるようにします。

```text
このエリアは満員です。少し待ってからもう一度お試しください。
```

## 表示を調整する

- 画面の重要な操作を隠さない位置にする
- 読み切れる表示時間にする
- 同じメッセージが重なって表示されないようにする
- ダークな背景と明るい背景の両方で読めるようにする

:::info 移動は実行されません
満員時メッセージは案内用です。定員判定そのものは[エリア・定員](./area-capacity)で正しく設定してください。
:::

## 確認する

定員まで入場した状態で別のプレイヤーが入口へ触れ、移動せずメッセージだけが表示されることを確認します。その後、1人が退出すると再び移動できることも確認してください。
