# 導入

<p className="lead-text">配布ファイルをUnityプロジェクトへ追加し、エラーがない状態まで確認します。</p>

## 導入前の確認

<ul className="check-list">
  <li>対象プロジェクトのバックアップまたはバージョン管理がある</li>
  <li>配布ページに記載された対応Unityバージョンを使用している</li>
  <li>必要な依存パッケージを先に導入している</li>
  <li>Consoleに既存のコンパイルエラーがない</li>
</ul>

:::caution 対応条件について
対応Unityバージョンと依存パッケージは、同梱のREADMEまたは配布ページにある最新版の案内を優先してください。
:::

## パッケージを追加する

配布形式に合った方法でファイルを追加します。インポート画面が表示された場合は、内容を確認してからすべての必要ファイルを取り込みます。

1. Unityプロジェクトを開く
2. 配布されたパッケージをインポートする
3. コンパイルが完了するまで待つ
4. **Console**を開き、赤いエラーがないことを確認する

<div className="screenshot-placeholder"><div><strong>パッケージ導入画面</strong><small>差し替え先: インポート対象がわかる画面</small></div></div>

## Prefabを確認する

Projectウィンドウで、テレポート用のPrefabと関連フォルダーを確認します。元Prefabは直接編集せず、必要に応じてPrefab Variantまたは複製を使うと更新時の差し替えが楽になります。

## 導入後のチェック

- Consoleに新しいエラーが出ていない
- 必要なPrefabがProjectウィンドウに表示される
- サンプルが同梱されている場合は、対応バージョンのシーンで開ける

準備ができたら、[クイックスタート](./quick-start)で最小構成を作ります。
