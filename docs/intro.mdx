# はじめに

<p className="lead-text">OKIYA式 テレポートギミック Ver.2 は、Unity上で入口と移動先を組み合わせ、用途に合ったテレポートを組み立てるためのギミックです。</p>

このガイドは、まず最小構成を動かし、そのあとでランダム移動、人数制限、分散、演出などを足していく順番で構成しています。

## このガイドの表記

- **GameObject名**、**コンポーネント名**、**Inspector項目**は太字で示します。
- 値や名称は、利用しているパッケージの版によって少し異なる場合があります。
- スクリーンショット枠は、実際のUnity画面へ後から差し替えられます。

:::tip 迷ったときは
最初からすべての機能を有効にせず、入口1つ・移動先1つの最小構成から確認すると原因を切り分けやすくなります。
:::

## 全体の流れ

1. Unityプロジェクトへパッケージを導入する
2. テレポートポイントを配置する
3. 入口と移動先を接続する
4. Play Modeで動作を確認する
5. 必要に応じて移動ルールや演出を追加する
