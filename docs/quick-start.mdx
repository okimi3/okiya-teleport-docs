# クイックスタート

<p className="lead-text">まずは「玄関だよ」から「リビングだぞ」へ、一方通行のテレポートを作ってみよう。操作はSceneに置いたPrefab本体のInspectorから進めます。</p>

## 1. PrefabをSceneに置く

配布フォルダの `01_これを使うよ！！` にある **OKIYA式_テレポートシステム_V2** Prefabを、Hierarchyへドラッグしてね。Scene上の **OKIYA式_テレポートシステム_V2** を選択すると、下のInspectorが表示されます。

![Prefab本体のInspector。テレポート管理などの項目が並ぶ](/img/screenshots/quick-start/system-inspector.png)

内部の参照はPrefabに設定されています。最初は **テレポート管理** を開けばOKです。

## 2. テレポート管理を開く

**テレポート管理** の中にある **テレポートポイント管理** と **テレポート接続管理** を開きます。先にポイントを用意してから、接続を設定する順番です。

![テレポート管理内のポイント管理と接続管理](/img/screenshots/quick-start/teleport-management.png)

## 3. 2つのポイントを用意する

**テレポートポイント管理** で、入口と出口を1つずつ用意します。ポイントが足りなければ **＋ テレポートポイントを追加** を押してね。Prefabにすでにポイントがある場合は、その2件を使えます。

| ポイント名の例 | ポイント種類 | 置く場所 |
| --- | --- | --- |
| 玄関だよ | テレポート入口 | プレイヤーが入る場所 |
| リビングだぞ | テレポート出口 | 到着させたい場所 |

各ポイントを開いて **ポイント名** と **ポイント種類** を設定します。**ポイントを選択** でScene上の対象を選び、位置と向きを調整してね。

![ポイント名、種類、選択、位置と回転を設定する画面](/img/screenshots/quick-start/point-details.png)

ポイント種類には **テレポート入口**、**テレポート出口**、**両方（入口＋出口）** があります。今回は入口と出口を選びます。

## 4. 入口と出口を接続する

**テレポート接続管理** で **＋ 接続を追加** を押します。接続がすでにある場合は、その接続を開いて設定してね。

![接続の設定画面。接続元、方式、方向、発動方法、テレポート先など](/img/screenshots/quick-start/connection-details.png)

最初の接続は、次のように設定します。

| 項目 | 設定する内容 |
| --- | --- |
| 接続元 | 玄関だよ |
| テレポート方式 | 通常 |
| 接続方向 | 一方通行 |
| 発動方法 | 接触 |
| テレポート先 | リビングだぞ |
| 利用モード | 全員 |

**接触** は入口に入ると発動する設定です。FadeはPrefab側の初期状態のままで、まず動作を確認しましょう。

## 5. Playして確認する

UnityでPlayを開始し、入口の判定へ入ってみてね。**リビングだぞ** にテレポートできれば完成です。到着位置や向きが気になるときは、出口の位置と回転を調整します。

:::tip うまくテレポートしないとき
接続元が入口、テレポート先が出口になっているか確認します。次に、入口の判定位置へプレイヤーが入っているかをSceneで見てみてね。
:::
