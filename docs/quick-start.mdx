# クイックスタート

<p className="lead-text">
まずは2つのテレポートポイントを使って、基本の一方通行テレポートを作ってみよう。<br />
このページの画面では、説明例としてポイントに名前を付けています。<br />
ポイント名は自由に変更してOKだよ。
</p>

## 1. PrefabをSceneに置く

配布フォルダの `01_これを使うよ！！` にある **OKIYA式_テレポートシステム_V2** Prefabを、Hierarchyへドラッグしてね。<br />
Scene上のPrefab本体を選択すると、Inspectorが表示されます。

![Prefab本体のInspector。テレポート管理などの項目が並ぶ](/img/screenshots/quick-start/system-inspector.png)

設定はPrefab本体のInspectorから進めます。<br />
最初は **テレポート管理** を開けばOKです。

## 2. テレポート管理を開く

**テレポート管理** の中にある **テレポートポイント管理** と **テレポート接続管理** を開きます。<br />
先にポイントを作り、そのあと接続を設定します。

![テレポート管理内のポイント管理と接続管理](/img/screenshots/quick-start/teleport-management.png)

## 3. ポイントを2つ作る

**テレポートポイント管理** で、入口と出口を1つずつ用意します。<br />
最初から2件ある場合は、そのポイントの種類と名前を変更して使ってね。<br />
足りないときは **＋ テレポートポイントを追加** を押します。

| 役割 | ポイント種類 | 名前の例 |
| --- | --- | --- |
| テレポートを開始する場所 | テレポート入口 | 玄関など |
| 到着する場所 | テレポート出口 | リビングなど |

各ポイントを開き、**ポイント種類** を設定します。<br />
**ポイント名** は自由です。場所や用途が分かる名前にすると、あとから管理しやすくなります。<br />
**ポイントを選択** でScene上の対象を選び、位置と向きを調整してね。

![ポイント名、種類、選択、位置と回転を設定する画面](/img/screenshots/quick-start/point-details.png)

画像内の名前や値は設定例です。<br />
ポイント種類には **両方（入口＋出口）** もありますが、ここでは入口と出口を1つずつ使います。

## 4. 入口と出口を接続する

**テレポート接続管理** で接続を1つ用意します。<br />
すでに接続がある場合は、その1件を開いて設定してね。<br />
なければ **＋ 接続を追加** を押します。

**接続元** には「テレポート入口」に設定したポイントを選びます。<br />
**テレポート先** には「テレポート出口」に設定したポイントを選びます。<br />
ほかの項目は、まず次のように設定してください。

| 項目 | 最初の設定 |
| --- | --- |
| テレポート方式 | 通常 |
| 接続方向 | 一方通行 |
| 発動方法 | 接触 |
| 利用モード | 全員 |

![接続の設定画面。接続元、方式、方向、発動方法、テレポート先など](/img/screenshots/quick-start/connection-details.png)

この画面例では、**「玄関だよ → リビングだぞ」** と設定しています。<br />
同じ名前にする必要はありません。<br />
**接触** は入口に入ると発動します。Fadeは最初の設定のままで、まず動作を確認しましょう。

## 5. Playして確認する

UnityでPlayを開始し、入口の判定へ入ってみてね。<br />
設定した出口へテレポートできれば完成です。<br />
到着位置や向きが気になるときは、出口の位置と回転を調整します。

:::tip うまくテレポートしないとき
接続元に入口、テレポート先に出口のポイントを選んでいるか確認します。<br />
次に、プレイヤーが入口の判定位置へ入っているかSceneで見てみてね。
:::
