# ランダム

<p className="lead-text">登録した複数のポイントから、移動のたびに行き先を選びます。</p>

## 向いている用途

- 行き先を予測できない演出
- ミニゲームの開始位置
- 複数の演出ポイントを均等な候補にしたい場合

## 設定する

1. 入口へ複数のテレポートポイントを登録する
2. 移動先の選択方法を**ランダム**にする
3. 候補に含めたくないポイントが登録されていないか確認する
4. Play Modeで繰り返し入り、複数の行き先が選ばれることを確認する

<div className="screenshot-placeholder"><div><strong>ランダム設定</strong><small>差し替え先: 選択方式と移動先リストが見えるInspector</small></div></div>

:::note ランダムと分散の違い
ランダムは行き先を抽選します。人数や混雑に応じて振り分けたい場合は、[分散](./distribution)を使います。
:::

## テストのポイント

数回のテストでは偏って見えることがあります。候補がすべて有効かを確認し、十分な回数を試してください。同じ場所への連続移動を避けたい場合は、該当する除外設定が用意されているか確認します。
