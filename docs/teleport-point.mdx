# テレポートポイント

<p className="lead-text">テレポートに使う場所は、Prefab本体のInspectorにある「テレポートポイント管理」から設定します。</p>

## 1. テレポートポイントとは

テレポートで使う場所を登録するためのポイントです。<br />
ポイントごとに **テレポート入口**、**テレポート出口**、**両方（入口＋出口）** の役割を選べます。

入口はテレポートを開始する場所、出口は到着する場所です。<br />
「両方」なら、1つのポイントを入口と出口の両方に使えます。

## 2. ポイントを追加する

Sceneに置いたPrefab本体を選び、**テレポート管理 → テレポートポイント管理** を開きます。<br />
**＋ テレポートポイントを追加** を押すと、一覧に新しいポイントが作られます。

![テレポートポイント管理に複数のポイントと追加ボタンが並ぶ](/img/screenshots/teleport-point/point-add.png)

## 3. ポイントの種類を選ぶ

追加したポイントを開き、**ポイント種類** から役割を選んでね。

![ポイント種類の選択肢。テレポート入口、テレポート出口、両方（入口＋出口）](/img/screenshots/teleport-point/point-type.png)

| 使い方 | 選ぶ種類 |
| --- | --- |
| 入口だけとして使う | テレポート入口 |
| 到着先だけとして使う | テレポート出口 |
| 行き来する場所など、両方に使う | 両方（入口＋出口） |

:::tip 迷ったら「両方」でOK
最初は **両方（入口＋出口）** にしておくと使いやすいです。<br />
同じポイントをテレポート元とテレポート先のどちらにも使えるので、双方向テレポートも設定しやすくなります。<br />
用途が決まっている場合は、入口専用・出口専用へ変更してね。
:::

## 4. ポイント名を付ける

**ポイント名** は自由に変更できます。<br />
画像の「玄関だよ」は場所が分かる名前の一例です。<br />
自分のワールドに合う名前を付けてね。

![ポイント名を入力しているInspectorの例](/img/screenshots/teleport-point/point-name.png)

名前が空欄なら、**A / B / C…** を使った名前が自動で付きます。

## 5. 一覧の見方

一覧には **01｜ポイント名｜ポイント種類** のように表示されます。<br />
**01 / 02 / 03…** は一覧の順番を示す番号です。<br />
名前を変更した後も、番号と種類をここで確認できます。

![名前を付けた2つのポイントが一覧に並ぶ](/img/screenshots/teleport-point/point-list.png)

画像の「玄関だよ」「リビングだぞ」は表示例です。<br />
同じ名前を入力する必要はありません。

## 6. ポイントを並び替える

各ポイントの右端にある **≡** をドラッグすると、一覧の順番を変えられます。<br />
変更した順番はHierarchy側にも反映されます。

![2つのポイントの右端に並び替えハンドルが見える](/img/screenshots/teleport-point/reorder.png)

## 7. 位置と向きを調整する

ポイントを開くと、Inspectorで **位置** と **回転** を確認・調整できます。<br />
**ポイントを選択** を押すと、対象のテレポートポイントをSceneView上で選択できます。<br />
**ポイントを表示** を使うと、SceneView上でポイントの場所を確認できます。

![ポイント名、種類、選択、表示、位置、回転を設定する画面](/img/screenshots/teleport-point/point-details.png)

位置はSceneViewのTransformハンドルを使って調整してね。<br />
Inspectorの **位置**・**回転** を直接入力して、位置と向きを調整することもできます。

![SceneView上で選択したテレポートポイントとXYZハンドル](/img/screenshots/teleport-point/scene-point-position.png)

テレポート先に設定したポイントの位置が、プレイヤーの到着位置の基準になります。<br />
到着後の正面は、Transformハンドルの **青い矢印（Z方向）** が基準です。<br />
プレイヤーを向かせたい方向へ、ポイントの **回転** を調整して青い矢印を合わせてね。<br />

画像では、向きを確認する例として置いた熊のオブジェクトと、青い矢印（Z方向）が同じ方向を向いています。<br />
この方向が、テレポート後にプレイヤーが向く正面の目安です。

矢印の色は **赤＝X、緑＝Y、青＝Z** です。

## 8. ポイントを削除する

使わないポイントは、開いたポイントの **このポイントを削除** から削除できます。<br />
接続などで使っている場合は、Inspectorに表示される案内を確認してね。

![ポイント削除ボタンとポイント追加ボタン](/img/screenshots/teleport-point/delete-add.png)
