# テレポートポイント

<p className="lead-text">テレポートに使う場所は、Prefab本体のInspectorにある「テレポートポイント管理」から設定します。</p>

## 1. テレポートポイントとは

テレポートで使う場所を登録するためのポイントです。ポイントごとに **テレポート入口**、**テレポート出口**、**両方（入口＋出口）** の役割を選べます。

入口はテレポートを開始する場所、出口は到着する場所です。「両方」なら、1つのポイントを入口と出口の両方に使えます。

## 2. ポイントを追加する

Sceneに置いたPrefab本体を選び、**テレポート管理 → テレポートポイント管理** を開きます。**＋ テレポートポイントを追加** を押すと、一覧に新しいポイントが作られます。

![テレポートポイント管理に複数のポイントと追加ボタンが並ぶ](/img/screenshots/teleport-point/point-add.png)

## 3. ポイントの種類を選ぶ

追加したポイントを開き、**ポイント種類** から役割を選んでね。

![ポイント種類の選択肢。テレポート入口、テレポート出口、両方（入口＋出口）](/img/screenshots/teleport-point/point-type.png)

| 使い方 | 選ぶ種類 |
| --- | --- |
| 入口だけとして使う | テレポート入口 |
| 到着先だけとして使う | テレポート出口 |
| 行き来する場所など、両方に使う | 両方（入口＋出口） |

## 4. ポイント名を付ける

**ポイント名** は自由に変更できます。画像の「玄関だよ」は場所が分かる名前の一例です。自分のワールドに合う名前を付けてね。

![ポイント名を入力しているInspectorの例](/img/screenshots/teleport-point/point-name.png)

名前が空欄なら、**A / B / C…** を使った名前が自動で付きます。

## 5. 一覧の見方

一覧には **01｜ポイント名｜ポイント種類** のように表示されます。**01 / 02 / 03…** は一覧の順番を示す番号です。名前を変更した後も、番号と種類をここで確認できます。

![名前を付けた2つのポイントが一覧に並ぶ](/img/screenshots/teleport-point/point-list.png)

画像の「玄関だよ」「リビングだぞ」は表示例です。同じ名前を入力する必要はありません。

## 6. ポイントを並び替える

各ポイントの右端にある **≡** をドラッグすると、一覧の順番を変えられます。変更した順番はHierarchy側にも反映されます。

![2つのポイントの右端に並び替えハンドルが見える](/img/screenshots/teleport-point/reorder.png)

## 7. 位置と向きを調整する

ポイントを開くと、Inspectorで **位置** と **回転** を確認・調整できます。**ポイントを選択** でScene上の対象を選び、**ポイントを表示** でSceneView上の場所を確認してね。

![ポイント名、種類、選択、表示、位置、回転を設定する画面](/img/screenshots/teleport-point/point-details.png)

テレポート出口では、ポイントの位置が到着位置、向きが到着後の向きの基準になります。

## 8. ポイントを削除する

使わないポイントは、開いたポイントの **このポイントを削除** から削除できます。接続などで使っている場合は、Inspectorに表示される案内を確認してね。

![ポイント削除ボタンとポイント追加ボタン](/img/screenshots/teleport-point/delete-add.png)
