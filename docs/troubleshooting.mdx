# トラブルシューティング

<p className="lead-text">うまく動かない場合は、まずConsoleのエラーを確認し、設定を最小構成へ戻して原因を切り分けます。<br />
上から順番に確認してね。</p>

## 最初に確認すること

- UnityのConsoleに赤いエラーが出ていないか。複数ある場合は、最初に出たエラーから確認する
- Prefab本体がScene内にあるか
- テレポート元・テレポート先が正しく登録されているか
- 対象GameObjectが無効になっていないか
- Play中だけ変更した設定ではないか
- まず **通常・1対1・双方向・接触・利用モード：全員** の最小構成で確認する

設定を変更するときはPlayを停止してね。<br />
基本の設定手順は、[クイックスタート](./quick-start)で確認できます。

## テレポート関連

### テレポートしない

1. 接続が作成され、テレポート元・テレポート先が設定されているか確認する
2. ポイント種類が意図した設定か確認する。双方向の基本例では両方のポイントを **両方（入口＋出口）** にする
3. 発動方法を確認する。**接触** はポイントの判定に入ると発動し、**トリガー** はポイントで操作すると発動する
4. 利用モードで拒否されていないか確認する
5. 分散の場合は、各候補の対応エリアを確認する
6. Consoleのエラーを確認する

関連：[テレポートポイント](./teleport-point)・[テレポート接続](./connection)・[利用制限](./access-restriction)

### 想定と違うテレポート先へ行く

- 接続のテレポート先が正しいか確認する
- ランダム・分散の候補に、意図したポイントが登録されているか確認する
- 同じ名前のポイントを取り違えていないか確認する
- **ポイントを選択**・**ポイントを表示** を使い、SceneViewでポイントの位置を確認する

到着場所は、青いZ方向ではなく **ポイントの位置そのもの** を確認してね。<br />
ランダム・分散では、選択方式に応じて別の候補が選ばれることがあります。

関連：[テレポートポイント](./teleport-point)・[ランダム](./random)・[分散](./distribution)

### 到着した向きがおかしい

テレポート先ポイントの **青いZ軸方向** が、到着後の正面方向です。<br />
プレイヤーを向かせたい方向へ合わせてね。

詳しくは、[テレポートポイント](./teleport-point)を確認してください。

### 到着直後に再テレポートする

- 到着地点が、別のテレポート元の判定と重なっていないか確認する
- 到着ポイントが接触判定の中に入り込んでいないか確認する
- ポイント位置を少し離して、もう一度試す

位置の確認方法は、[テレポートポイント](./teleport-point)で確認できます。

## ランダム・分散

### ランダムで特定候補へ行かない

- 候補の **使用する** がONか
- **確率** が0になっていないか
- テレポート先が正しく設定されているか
- 抽選回数が少なすぎないか

数回だけでは、設定した割合どおりに見えないことがあります。<br />
設定と抽選プレビューは、[ランダム](./random)で確認してね。

### 分散が思った通りに選ばれない

1. 各候補の **テレポート先＋対応エリア** を確認する
2. 分散方法が意図した方式か確認する
3. Play中の各エリアの **現在人数・定員・空き人数・混雑率・満員状態** を確認する
4. 最良条件が同じ候補の **同率時抽選** の設定値を確認する

**分散条件が先、同率時抽選が後** です。<br />
最良条件の候補が1つなら、その候補が選ばれます。<br />
満員候補は通常の分散対象から外れるため、全候補満員時の設定も確認してね。

詳しくは、[分散](./distribution)を確認してください。

## エリア・定員

### エリア人数が合わない

- SceneViewのBoxが、人数を数えたい場所を高さも含めて覆っているか
- コライダーサイズが狭すぎないか
- 他のエリアと範囲が重なっていないか
- カウント除外に対象プレイヤーの表示名が登録されていないか
- ポイント追従の対象ポイントや位置オフセットが正しいか
- Play中の **現在状態** に表示される人数がどう変化するか

カウント除外の表示名は完全一致です。<br />
詳しくは、[エリア・定員](./area-capacity)を確認してね。

### 満員判定がおかしい

- エリアの定員と現在人数を確認する
- カウント除外と判定範囲を確認する
- 分散候補の対応エリアが、意図したエリアか確認する
- 分散側の満員候補の扱いと、全候補満員時の設定を確認する

関連：[エリア・定員](./area-capacity)・[分散](./distribution)

## 満員時メッセージ

### 満員なのにメッセージが出ない

1. 分散を使用しているか確認する
2. 一部だけでなく、全候補が満員か確認する
3. **全候補が満員の場合 → テレポートしない** になっているか確認する
4. Prefab本体の **満員時メッセージデザイン** が設定されているか確認する
5. Play中に、表示を確認したい本人がテレポートを試す

メッセージはテレポートしようとした本人へ表示されます。<br />
設定方法は、[満員時メッセージ](./full-message)を確認してね。

## Fade

### Fadeが表示されない

- 接続側の **Fadeを使用** がONか
- 接続のFade時間が意図した設定か
- 共通Fadeデザインの背景色・Fade画像が設定されているか
- 画像を使う場合、PNGが **Sprite (2D and UI)** に設定されているか

関連：[Fade](./fade)・[画像素材の使い方](./image-assets#png-import)

### Fade後に画面が戻らない

1. Consoleのエラーと、接続の **Fade In** 時間を確認する
2. 連続テレポート時だけ起こるか確認する
3. Fadeを一度OFFにし、テレポート本体だけで動作を確認する
4. FadeをONへ戻し、もう一度確認する

テレポートと演出を分けて確認すると、原因を絞り込みやすくなります。<br />
設定方法は、[Fade](./fade)を確認してね。

## 到着通知

### 到着通知が表示されない

- 対象エリアの **到着通知を使用** がONか
- **到着した本人** の **通知を表示する** が意図した設定か
- **到着先にいるプレイヤー** の **通知を表示する** が意図した設定か
- 表示時間が意図した設定か
- Desktop表示位置、VRの場合はVR表示位置が適切か
- 対象エリアへ実際にテレポートしているか

設定方法は、[到着通知](./arrival-notification)で確認できます。

### 到着通知の音が鳴らない

- 対象の **通知音を鳴らす** がONか
- AudioClipが設定されているか
- ランダムの場合は音の候補が登録されているか
- 音量と **SE終了後クールタイム** が意図した設定か

通知音素材は商品・配布データに付属しません。<br />
音の設定方法は、[到着通知](./arrival-notification)を確認してね。

## 画像関連

### PNGを画像欄へ設定できない

1. ProjectビューへPNGを取り込んだか確認する
2. **Texture Type** が **Sprite (2D and UI)** か確認する
3. **Apply** を押したか確認する

詳しくは、[画像素材の使い方：PNGをUnityへ取り込む](./image-assets#png-import)を確認してね。

### Sprite Editorが開かない

9-slice用のBorder設定には、Unityの **2D Sprite** パッケージが必要です。<br />
通常のPNGをそのまま使う場合は、Sprite Editorを開く必要はありません。

9-sliceを使いたい場合は、[画像素材の使い方：9-slice](./image-assets#nine-slice)を確認してね。

## Unity全般

### Play Modeで設定した値が戻った

Unityでは通常、Play Mode中のInspector変更は、Play終了時に元へ戻ります。<br />
Playを停止してから設定し直してね。

### Consoleにエラーが出る

Consoleの赤いエラーは、一番上のもの・最初に出たものから確認します。<br />
同じエラーが大量に出ていても、最初の原因を確認してね。

- Unityのバージョン
- UdonSharp・VRChat SDKのバージョン
- 導入直後から発生していたか
- 設定やデータの変更後から発生したか

これらを確認し、発生する条件を整理してください。

## 解決しない場合

解決しない場合や不具合と思われる挙動がある場合は、Xの [@eszou3](https://x.com/eszou3) まで連絡してください。<br />
次の情報があると状況を確認しやすくなります。

- Unityのバージョン
- ギミックのバージョン
- 発生までの短い手順
- Hierarchyのスクリーンショット
- Inspectorのスクリーンショット
- Consoleエラー全文
- Desktop・VRのどちらで発生したか
- 可能なら再現条件

仕様についての質問は、[FAQ](./faq)も確認してね。
