# アップデート

<p className="lead-text">
現在の設定を守りながら、新しいバージョンへ更新するための基本手順です。<br />
アップデート前にバックアップを取り、最新版のUnityPackageを同じプロジェクトへインポートして更新します。<br />
更新後は、既存設定と主要機能がそのまま動くかを確認してね。
</p>

## 1. 更新前に行うこと

1. **Play Modeを終了する**
2. Scene・Prefab・その他編集中の内容を保存する
3. Unityプロジェクト全体をバックアップする
4. 現在使用している配布ファイルや、導入時のバージョンを控える
5. 最新版の更新案内を確認する
6. 更新前のConsoleを確認し、すでにあるエラーを記録する

Play中のInspector変更は、Play終了時に元へ戻ることがあります。<br />
更新作業と設定変更は、Playを停止した状態で行ってね。

:::warning 更新前に必ずバックアップを用意してね
Unityプロジェクト全体のバックアップを強くおすすめします。<br />
何かあった場合に、更新前の状態へ戻せるようにしておくためです。<br />
Gitなどで管理している場合は、必要なファイルが管理対象に含まれていることを確認し、更新直前の状態をコミットしておく方法でも構いません。
:::

### 独自改変がある場合

配布されたC#・UdonSharpスクリプト、Editorスクリプト、Prefab内部、配布素材を直接変更している場合は、更新で上書きされる可能性があります。<br />
独自改変の内容も、更新前に必ずバックアップしてね。

## 2. 最新版UnityPackageをインポートする

最新版の **101_OKIYA式_テレポートギミック_V2.unitypackage** を用意します。<br />
通常のアップデートでは、**旧版の配布フォルダやScene上のPrefabを先に削除せず**、現在使用している同じUnityプロジェクトへインポートします。<br />
旧版を先に削除すると、参照や設定が失われる可能性があります。

:::note バージョンごとの更新案内を確認してね
特定バージョンの更新案内で別の手順が指定されている場合は、その案内を優先してください。
:::

1. 現在使用しているUnityプロジェクトで、最新版のUnityPackageを開く
2. **Import Unity Package** に表示される内容を確認する
3. 基本的には配布ファイルをすべてチェックした状態で **Import** を押す
4. インポートが完了し、コンパイルが終わるまで待つ
5. Consoleに新しい赤いエラーが出ていないか確認する

インポート画面の見方は、[クイックスタート](./quick-start)で確認できます。<br />
更新後は、Sceneに配置済みの **OKIYA式テレポートシステム** をまずそのまま選択して確認してね。

## 3. 既存設定について

通常のアップデートでは、Scene上で設定済みのポイント・接続・エリアなどをできるだけ引き継げるように作られています。<br />
ただし、更新後は必ず設定内容と動作を確認してください。

コードの直接変更、Prefab内部の大きな改変、古いバージョンからの大きな更新などでは、特に確認が必要です。<br />
どのバージョンや改変状態でも、設定が必ず100％保持されることを保証するものではありません。

## 4. 更新後に確認する

### Consoleと既存設定を確認する

コンパイルが終わったら、更新前のConsoleと比較して、新しい赤いエラーが出ていないか確認します。<br />
Scene上の既存Prefabを選択し、更新前の設定が残っているか見てね。

- テレポートポイント・テレポート接続
- 利用制限
- エリア
- ランダム・分散の候補
- Fade
- 満員時メッセージ
- 到着通知

まずは設定の確認を行い、そのあとPlayで動作を確認します。

### 通常の1対1テレポートから試す

最初に、**通常・1対1の基本テレポート** が正常に動くか確認してね。<br />
基本動作を確認できたら、使用している機能を中心に順番に試します。

- [ ] 通常の1対1テレポート
- [ ] 一方通行・双方向
- [ ] 接触・トリガー
- [ ] 利用制限
- [ ] ランダム
- [ ] エリア人数・定員
- [ ] 分散
- [ ] 満員時メッセージ
- [ ] Fade
- [ ] 到着通知
- [ ] Desktopで使用する表示
- [ ] VRを使用する場合は、VR側の表示

使用していない機能まで、すべて確認する必要はありません。<br />
人数・分散・到着通知など、複数プレイヤーが関係する機能を使っている場合は、可能なら複数クライアント・複数人でも確認すると分かりやすいです。

**✓ 更新前の設定が残り、使用中の機能が正常に動けばOKです。**

## 5. 問題が起きた場合

1. Consoleの最初の赤いエラーを確認する
2. 更新前のバックアップ側でも、同じ問題が発生するか確認する
3. 最小構成の通常テレポートで確認する
4. 問題がある機能だけを順番に確認する
5. 必要なら、更新前のバックアップへ戻す

詳しい切り分けは、[トラブルシューティング](./troubleshooting)を確認してね。

### 解決しない場合

解決しない場合は、Xの [@eszou3](https://x.com/eszou3) まで連絡してください。<br />
次の情報があると状況を確認しやすくなります。

- 更新前のバージョン
- 更新後のバージョン
- Unityのバージョン
- 発生までの短い手順
- Inspectorのスクリーンショット
- Consoleエラー全文
- 更新前のバックアップでも発生するか
