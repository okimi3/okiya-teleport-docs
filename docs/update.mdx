# アップデート

<p className="lead-text">現在の設定を守りながら、新しいバージョンへ更新するための基本手順です。</p>

## 更新前に行うこと

<ul className="check-list">
  <li>プロジェクト全体をバックアップまたはコミットする</li>
  <li>現在使用中のバージョンを記録する</li>
  <li>変更履歴と破壊的変更を確認する</li>
  <li>Prefabへ直接加えた変更を確認する</li>
</ul>

## 更新する

1. Unityを閉じる前に、未保存のSceneとPrefabを保存する
2. 配布元の手順に従って新しいファイルを導入する
3. コンパイル完了後、Consoleのエラーを確認する
4. テスト用Sceneで最小構成を確認する
5. 本番Sceneで各機能を順番に確認する

:::warning 上書きに注意
配布Prefabやスクリプトを直接変更していると、アップデートで上書きされる場合があります。独自設定はPrefab Variantや別コンポーネントへ分離してください。
:::

## 更新後の確認項目

- 基本の1対1テレポート
- 複数移動先の選択
- エリア人数と定員
- 満員時メッセージ
- Fadeと到着通知
- 複数クライアントでの挙動

## 問題が起きたら

Consoleの最初のエラーから確認します。問題が更新前からあったか判断できるよう、バックアップ側のプロジェクトでも同じ手順を再現します。解決できない場合は、Unityバージョン、ギミックのバージョン、再現手順、Consoleログをまとめてください。
